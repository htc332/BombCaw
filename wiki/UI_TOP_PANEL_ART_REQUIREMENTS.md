# 上半部分UI美术需求文档

## 1. 需求概述

针对当前游戏主界面上半部分（关卡信息 + 统计信息区域）进行UI美术设计，使其从"测试感"转变为"正式感"。

**当前问题**：
- 关卡信息和统计信息是纯文字，无背景、无装饰
- 与棋盘之间缺乏视觉过渡
- 整体显得简陋，像是临时占位符

**设计目标**：
- 保持与游戏整体风格一致（深色背景、鼠尾草绿棋盘、暖色调点缀）
- 增加UI背景板和装饰元素
- 提升信息可读性和视觉层次

---

## 2. 整体风格参考

### 2.1 游戏现有配色

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景色 | `#1A1A2E` | 深蓝紫黑，主背景 |
| 棋盘主色 | `#3B5B4B` | 鼠尾草绿，低对比护眼 |
| 棋盘交替色 | `#4A6B5A` | 比主色亮7% |
| 金色点缀 | `#FFD700` | 关卡文字、重要信息 |
| 米色文字 | `#E8D5C0` | 统计信息、次要文字 |
| 暖白文字 | `#FFF0D4` | 得分数字、主文字 |

### 2.2 设计原则

- **深色半透明**：UI背景使用深色半透明，不遮挡背景图
- **圆角现代感**：所有UI元素使用圆角，避免尖锐直角
- **暖色点缀**：金色/米色用于重要信息和装饰
- **层次分明**：通过阴影、描边、透明度创造层次

## 3. 具体美术需求

### 3.1 信息区域背景板

**位置**：关卡信息和统计信息的外层容器

**需求**：
- 圆角矩形背景板（圆角半径 12-16px）
- 填充色：`rgba(13, 13, 21, 0.85)`（深色半透明）
- 边框：1px 细线，`rgba(74, 74, 90, 0.6)`（暗灰紫色）
- 内边距：上下 12px，左右 20px
- 可选：轻微内阴影 `inset 0 1px 0 rgba(255,255,255,0.05)`

**视觉参考**：类似底部购买栏的背景风格，但透明度略低

---

### 3.2 关卡信息区域

**位置**：背景板内上半部分

**当前显示**：`关卡: 1`

**优化方案**：

#### 3.2.1 图标 + 文字组合
- **左侧**：小图标（关卡/旗帜符号）
  - 尺寸：20×20px
  - 颜色：`#FFD700`（金色）
  - 风格：简约线条图标
- **右侧**：关卡数字
  - 字体：粗体，18-20px
  - 颜色：`#FFD700`（金色）
  - 增加文字阴影：`0 2px 4px rgba(0,0,0,0.5)`

#### 3.2.2 装饰元素
- 数字两侧可增加小星星或点点装饰
- 或：数字下方增加细横线作为分隔

---

### 3.3 统计信息区域

**位置**：背景板内下半部分，与关卡信息有分隔

**当前显示**：`消灭:0只  剩余:5只`

**优化方案**：

#### 3.3.1 双栏布局
```
┌─────────────────────────┐
│  🐭 消灭: 0只    ⏱ 剩余: 5只  │
└─────────────────────────┘
```

#### 3.3.2 左侧 - 消灭数量
- **图标**：老鼠简笔画或靶心图标
  - 尺寸：16×16px
  - 颜色：`#E8D5C0`（米色）
- **文字**："消灭: X只"
  - 字体：常规，14px
  - 颜色：`#E8D5C0`（米色）
- **数字**：加粗，颜色 `#FFD700`（金色）

#### 3.3.3 右侧 - 剩余数量
- **图标**：时钟或沙漏图标
  - 尺寸：16×16px
  - 颜色：`#E8D5C0`（米色）
- **文字**："剩余: X只"
  - 字体：常规，14px
  - 颜色：`#E8D5C0`（米色）
- **数字**：加粗，颜色 `#FF6B6B`（柔和红色，表示紧迫感）

#### 3.3.4 分隔线
- 两栏之间：1px 竖线分隔
- 颜色：`rgba(255,255,255,0.1)`

---

### 3.4 与棋盘的过渡区域

**问题**：信息区域和棋盘之间目前是纯空白，有100px间隔

**优化方案**：

#### 3.4.1 渐变过渡
- 在信息区域底部到棋盘顶部之间
- 添加渐变遮罩：从 `rgba(13,13,21,0.3)` 渐变到透明
- 高度：30-40px

#### 3.4.2 装饰性分隔线
- 信息区域底部：细横线 + 两侧小装饰
- 类似：`─── ✦ ───` 的简化版
- 颜色：`rgba(255,215,0,0.3)`（淡金色）

## 5. 技术实现说明

### 5.1 代码修改点

#### Renderer.js
- `drawLevel()`：改为绘制图标+文字组合
- `drawStats()`：改为双栏布局，增加图标
- 新增 `drawTopPanel()`：绘制背景板

#### 资源加载
- 在 `loadSubpackageImages()` 中新增图标加载
- 路径：`res/ui/icon_*.png`

### 5.2 性能考虑

- 所有UI元素使用静态图片，无动画
- 背景板使用9宫格拉伸，避免大图
- 图标尺寸控制在40px以内，节省内存

---

## 6. 验收标准

- [ ] 信息区域有正式UI背景板，非纯文字
- [ ] 关卡信息包含图标，视觉突出
- [ ] 统计信息双栏显示，有图标分隔
- [ ] 与棋盘之间有视觉过渡，不生硬
- [ ] 配色与游戏整体风格一致
- [ ] 不同屏幕尺寸下显示正常
- [ ] 性能无影响（60fps保持）

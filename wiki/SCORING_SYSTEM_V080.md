# 牛牛炸鼠 v0.8.0 新计分系统设计文档

## 一、设计目标

将游戏经济系统从"有限炸弹+复杂得分"简化为"积分驱动+无限放置"，降低玩家理解成本，增强策略深度。

---

## 二、核心规则

### 2.1 积分系统

| 规则 | 数值 | 说明 |
|------|------|------|
| **初始积分** | 10分 | 每局开始固定10分 |
| **积分保留** | 通关保留 | 过关后积分带入下一关 |
| **积分重置** | 失败重置为10分 | 闯关失败回到最初关卡，积分重置 |
| **炸弹消耗** | LV1:2, LV2:3, LV3:4, LV4:5 | 放置时立即扣除 |
| **炸鼠收益** | +1分/只 | 所有老鼠墙统一+1分 |
| **炸弹数量** | 无限 | 积分足够可无限放置 |
| **失败条件** | 积分≤0且无敌方炸弹 | 已放置的炸弹爆炸完再判定 |

### 2.2 经济循环

```
开始: 10分
  ↓
放置炸弹 → 扣分 (2/3/4/5)
  ↓
炸鼠 → +1分/只
  ↓
积分>0 → 继续放置
积分≤0 → 无法放置 → 失败 → 重置10分
```

**关键设计**：放炸弹净亏（最少-1分），必须**一次炸多只鼠**才能盈利。鼓励玩家规划炸弹位置，利用范围重叠。

## 三、爆炸范围规则

### 3.1 各等级范围

| 等级 | 消耗 | 形状 | 范围描述 |
|------|------|------|----------|
| **LV1** | 2分 | 十字 | 上下左右各1格 |
| **LV2** | 3分 | 竖直 | 上下各3格 |
| **LV3** | 4分 | 横向+上 | 左右各3格，上方1格 |
| **LV4** | 5分 | 十字+对角 | 上下左右各1格 + 四角对角1格 |

### 3.2 范围示意图

```
LV1 (十字1格)        LV2 (竖直3格)        LV3 (横向+上)         LV4 (十字+对角)
  . X .                . X .                . X .                X X X
  X B X                . X .                X X X                X B X
  . X .                . B .                . B .                X X X
                       . X .
                       . X .
```

## 四、关卡适配

### 4.1 配置变更

所有关卡移除 `bombs` 字段，不再限制炸弹数量。

**示例关卡配置（第2关）**：
```javascript
2: {
  gridSize: 5,
  hint: '引爆中间的炸弹，看它如何帮你炸掉所有墙壁',
  walls: [
    { x: -2, y: 0, type: 'normal' },
    { x: 2, y: 0, type: 'normal' },
    { x: 0, y: -2, type: 'normal' },
    { x: 0, y: 2, type: 'normal' }
  ],
  staticBombs: [
    { x: 0, y: 0, evolution: 0 },
    { x: -1, y: 0, evolution: 0 },
    { x: 0, y: -1, evolution: 0 },
    { x: 0, y: 1, evolution: 0 }
  ]
}
```

### 4.2 关卡设计原则

- **静态炸弹是"免费收益"**：激活不消耗积分，炸鼠+1分
- **范围重叠是关键**：鼓励玩家让多个炸弹范围覆盖同一区域
- **LV2/LV3有方向性**：竖直/横向布局的关卡更适合对应等级

## 六、技术实现

### 6.1 修改文件清单

| 文件 | 修改内容 | 优先级 |
|------|----------|--------|
| `GameLogic.js` | 核心计分逻辑、爆炸范围、失败判定 | P0 |
| `Config.js` | 炸弹类型配置、计分配置 | P0 |
| `main.js` | 事件处理、结算UI、失败重置 | P0 |
| `Renderer.js` | 顶部得分面板绘制 | P0 |
| `UIManager.js` | 购买栏显示消耗积分 | P0 |
| `LevelData.js` | 移除所有`bombs`字段 | P0 |
| `Animator.js` | 爆炸特效适配新范围 | P1 |

### 6.2 关键数据结构

```javascript
// 游戏状态
{
  score: 10,           // 当前积分
  selectedBombType: 0, // 选中炸弹等级
  bombsPlaced: 0,       // 本局已放置数
  wallsDestroyed: 0,   // 本局已消灭数
  // ... 其他原有字段
}

// 炸弹类型配置
[
  { level: 1, cost: 2, evolution: 0 },  // 白色
  { level: 2, cost: 3, evolution: 2 },  // 蓝色
  { level: 3, cost: 4, evolution: 3 },  // 紫色
  { level: 4, cost: 5, evolution: 5 }   // 红色
]
```

### 6.3 关键算法

**放置炸弹**：
```javascript
const bombCosts = [2, 3, 4, 5];
const cost = bombCosts[selectedType];

if (score < cost) {
  return false; // 积分不足，无法放置
}

score -= cost; // 扣除积分
bombsPlaced++; // 统计
```

**爆炸范围计算**：
```javascript
// LV2: 竖直上下各3格
const dirs = [[0,1], [0,-1]];
dirs.forEach(([dx, dy]) => {
  for (let d = 1; d <= 3; d++) {
    range.push({ x: bomb.x + dx*d, y: bomb.y + dy*d });
  }
});

// LV3: 横向左右各3格 + 上方1格
const hDirs = [[1,0], [-1,0]];
hDirs.forEach(([dx, dy]) => {
  for (let d = 1; d <= 3; d++) {
    range.push({ x: bomb.x + dx*d, y: bomb.y + dy*d });
  }
});
range.push({ x: bomb.x, y: bomb.y - 1 }); // 上方1格
```

**失败判定**：
```javascript
// 分数<=0 且 没有待爆炸的炸弹（动态炸弹+静态炸弹）
const hasPendingBombs = bombs.size > 0 || 
  staticBombs.some(sb => sb.active);

if (score <= 0 && !hasPendingBombs) {
  gameActive = false;
  emit('level_failed', { reason: 'out_of_score' });
}
```

## 七、边界情况处理

| 情况 | 处理 |
|------|------|
| 分数刚好为0，还有已放置炸弹 | 等待炸弹爆炸完再判定 |
| 炸弹墙死亡 | 不再返还炸弹，改为+1分奖励 |
| 静态炸弹激活 | 不再额外加分，只触发爆炸 |
| 复活（广告） | 给5分救命，而非给炸弹 |
| 连击爆炸 | 无额外奖励，每只鼠统一+1分 |

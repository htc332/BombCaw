# 炸弹牛游戏 - 上部分UI设计需求文档

## 项目概述

**游戏名称**: 炸弹牛 (Bomb Wall Canvas)  
**目标平台**: 微信小游戏（竖屏）  
**版本**: v0.8.0  
**设计目标**: 将现有Canvas绘制UI替换为专业美术资源，提升视觉品质

---

## 上部分UI区域划分

游戏画面上半部分分为**3个功能区域**（从上到下）：

```
┌─────────────────────────────────┐
│  ① 功能按钮区 (funcBtnH)        │  ← 顶部
│  ┌───────────────────────────┐  │
│  │ 关卡: 1 ⭐  │  剩余鼠鼠: 5🐭│  │
│  └───────────────────────────┘  │
├─────────────────────────────────┤
│  ② 得分/积分区 (scoreH)         │  ← 中部
│  ┌───────────────────────────┐  │
│  │ 积分: 10  │ 已放: 0 消灭: 0 │  │
│  └───────────────────────────┘  │
├─────────────────────────────────┤
│                                 │
│      ③ 游戏棋盘区域              │  ← 下方（不在本次设计范围）
│                                 │
└─────────────────────────────────┘
```

## 区域①：功能按钮区

### 功能说明
- 显示当前关卡编号
- 显示剩余老鼠数量（胜利条件）
- 提供设置/返回按钮入口

### 当前实现（Canvas绘制）
```javascript
// 背景：深色半透明圆角矩形
ctx.fillStyle = 'rgba(13, 13, 21, 0.85)';
// 圆角半径: 12px * scale

// 左侧：关卡信息
// 文字: "关卡:" + 数字 + ⭐星星图标
// 颜色: 金色(#FFD700) + 白色(#FFF)
// 字号: 16px / 18px (bold)

// 右侧：剩余老鼠
// 文字: "剩余鼠鼠:" + 数字 + 🐭老鼠图标
// 颜色: 白色(#FFF) + 金色(#FFD700)
// 字号: 16px / 20px (bold)
```

### 设计需求

#### 1. 背景底板
- **样式**: 深色半透明圆角矩形
- **颜色**: 接近 `#0D0D15` 或 `#1A1A2E`，带85%透明度
- **圆角**: 12px（需适配不同屏幕缩放）
- **高度**: 约50px（基准375px宽度屏幕）
- **阴影**: 轻微下沉阴影，增加层次感

#### 2. 关卡显示（左侧）
- **图标**: 星星/旗帜/关卡图标（替代文字"关卡:"）
- **数字**: 大号白色数字，突出当前关卡
- **装饰**: 已完成关卡可用金色星星标记

#### 3. 剩余老鼠（右侧）
- **图标**: 老鼠头像/剪影（替代emoji 🐭）
- **数字**: 金色大号数字，醒目显示
- **文字**: 可保留"剩余"或简化为图标+数字

#### 4. 设置按钮（可选）
- **位置**: 右上角或左上角
- **图标**: 齿轮/菜单图标
- **样式**: 与背景协调的简洁图标

## 区域②：得分/积分区

### 功能说明（v0.8.0新计分系统）
- **核心积分**: 当前可用积分（牛奶=积分）
- **统计信息**: 已放置炸弹数、已消灭老鼠数
- **加分动画**: 炸弹得分/消灭老鼠时的飘字动画

### 当前实现（Canvas绘制）
```javascript
// 背景：半透明面板
ctx.fillStyle = 'rgba(13, 13, 21, 0.6)';

// 左侧：当前积分（大字体突出）
// 文字: "积分:" + 数字
// 颜色: 金色(#FFD700)标题 + 白色(#FFF)数字
// 字号: 24px / 28px (bold)

// 右侧：本局统计
// 文字: "已放炸弹: X颗" / "消灭老鼠: X只"
// 颜色: 米色(#E8D5C0)
// 字号: 14px

// 飘字动画（加分时）
// 绿色(+1)文字向上飘，2秒淡出
```

### 设计需求

#### 1. 背景面板
- **样式**: 半透明背景，与功能按钮区区分但协调
- **颜色**: `rgba(13, 13, 21, 0.6)` 或类似深色半透明
- **高度**: 约100px（基准375px宽度屏幕）
- **分隔**: 与上下区域有 subtle 分隔线或阴影

#### 2. 积分显示（左侧重点）
- **图标**: 牛奶瓶图标（核心视觉元素）
  - 当前使用: `images/ui_grid.png` 作为牛奶图标
  - 需求: 更精致的牛奶瓶/牛奶盒图标
- **数字**: 大号白色数字，28px+，bold
- **标签**: "积分"或直接用图标表示
- **动态效果**: 积分变化时有缩放/跳动动画

#### 3. 统计信息（右侧）
- **炸弹统计**: 炸弹图标 + 数字 + "颗"
- **消灭统计**: 老鼠图标 + 数字 + "只"
- **样式**: 较小字号（14px），米色/浅灰色
- **布局**: 上下排列或水平排列

#### 4. 飘字动画素材（加分反馈）
- **+1 飘字**: 绿色/金色，向上飘动，2秒淡出
- **炸弹消耗**: 红色飘字（-2, -3, -4, -5）
- **样式**: 粗体，带轻微阴影或描边，确保在背景上可见

## 核心视觉元素清单

### 需要设计的图标/素材

| 元素 | 用途 | 尺寸建议 | 备注 |
|------|------|----------|------|
| 牛奶瓶图标 | 积分单位 | 32x32px | 核心视觉，需精致 |
| 星星图标 | 关卡标记 | 16x16px | 金色，可动画 |

| 炸弹图标 | 统计信息 | 16x16px | 与游戏内炸弹一致 |

| 飘字背景 | 加分动画 | 动态 | 可选，文字可直接带描边 |

### 颜色规范

```
主背景:     #1A1A2E (深蓝黑)
面板背景:   rgba(13, 13, 21, 0.6~0.85) (半透明深色)
主文字:     #FFFFFF (白色)
强调色:     #FFD700 (金色) - 用于数字、星星
次要文字:   #E8D5C0 (米色)
成功/加分:  #4CAF50 (绿色)
失败/消耗:  #FF4444 (红色)
提示文字:   #F0E6D3 (奶油色)
```

## 布局规格（基准屏幕：375px宽度）

```
屏幕总高: 667px (iPhone 6/7/8 基准)

功能按钮区高度: 50px
  - 顶部安全区: 自动适配刘海屏
  - 背景圆角: 12px
  - 内边距: 左右15px

得分区高度: 100px
  - 内边距: 左右15px
  - 积分数字: 28px bold
  - 统计文字: 14px

棋盘区域: 剩余空间
  - 居中显示
  - 5x5格子基准
```

**适配要求**:
- 所有尺寸基于 `scale = windowWidth / 375` 动态缩放
- 支持 iPhone 6/7/8 (375px) 到 iPhone 14 Pro Max (430px+) 的宽度适配
- 刘海屏/灵动岛自动避让安全区

## 风格参考

### 现有游戏风格
- **整体**: 暗黑系休闲益智，深色背景+亮色点缀
- **棋盘**: 鼠尾草绿色系格子 (`#3B5B4B` / `#4A6B5A`)
- **炸弹牛**: 4种颜色等级（白/蓝/紫/红）
- **墙壁**: 暖色调（黄/红）

### 期望UI风格
- **扁平化 + 轻质感**: 不追求重度拟物，但要有层次
- **圆角现代**: 与微信小游戏设计规范一致
- **高对比可读**: 确保在复杂背景上文字清晰
- **动画友好**: 元素需支持缩放、淡入淡出、位移动画

## 交付物要求

### 1. 独立PNG图标
- 格式: PNG-24，透明背景
- 尺寸: 按上述规格，提供1x和2x版本
- 命名规范: `ui_milk.png`, `ui_star.png`, `ui_rat.png` 等

### 2. 背景/面板素材（如需要）
- 9宫格拉伸背景（如圆角面板）
- 或提供可复用的底板样式参数

### 3. 可选：字体建议
- 当前使用系统默认 sans-serif
- 如需定制字体，请提供 TTF/OTF 文件
- 中文字体需考虑文件大小（微信小游戏限制）

### 4. 动画参数（如提供动态素材）
- 飘字动画时长: 2秒
- 积分变化动画: 0.3秒缩放
- 支持帧动画或代码动画

## 备注

1. **牛奶=积分**: 这是v0.8.0的核心概念变更，UI中所有"积分"都用牛奶图标表示，避免文字歧义
2. **微信小游戏限制**: 总包大小4MB，图片需压缩优化
3. **动态适配**: 所有UI元素需考虑不同屏幕比例的缩放
4. **当前临时方案**: 部分UI使用emoji（⭐🐭）和Canvas绘制，需全部替换为美术资源

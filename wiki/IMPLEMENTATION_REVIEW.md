## 1. 分包系统 (subpackage)

### 设计目标
- 主包 ≤ 2MB（微信小游戏限制）
- 子包按需加载，减少首次启动时间
- 资源分类管理：UI、精灵图、音效

### 实现结构
```
subpackage/
├── ui/                          # UI 资源
│   ├── Login.png               # 登录界面
│   ├── Loading.png             # 加载界面
│   └── game_bg_small.png       # 游戏背景（压缩后414KB）
├── sprites/                     # 精灵图资源
│   ├── lv1~lv4/                # 动态炸弹精灵图（4级）
│   │   ├── sprite.png          # 精灵图合图
│   │   └── index.json          # 帧索引配置
│   ├── enemy_elite/            # 精英鼠
│   ├── enemy_n/                # 普通鼠
│   ├── enemy_n_death/          # 普通鼠死亡动画
│   ├── enemy_elite_break/      # 精英鼠头盔破损过渡
│   ├── enemy_elite_break_idle/ # 精英鼠破损后待机
│   ├── enemy_elite_death/      # 精英鼠死亡动画
│   └── static_bombs/Sleep/     # 静态炸弹Sleep图片
│       ├── Sleep_lv1~4.png
└── audio/                       # 音效资源（预留）
```

### 关键技术
- **加载策略**: `Promise.all()` 并行加载所有资源
- **错误处理**: 单个资源加载失败不影响其他资源（`resolve(null)`）
- **索引对齐**: promises 数组索引与 results 严格对应（27个元素）
- **历史教训**: 添加 `game_bg_small.png` 时漏掉 `enemy_elite_death`，导致所有精灵图索引错位

### 当前配置
| 资源类型 | 大小策略 | 状态 |
|---------|---------|------|
| 主包 | ≤ 2MB | ✅ 通过 |
| 背景图 | 414KB（压缩后） | ✅ 已优化 |
| 精灵图 | 子包加载 | ✅ 正常 |

## 2. 动画系统

### 2.1 动态炸弹动画
- **类型**: 帧动画（倒计时进度驱动）
- **帧数**: 每级炸弹约 10-15 帧
- **播放方式**: 非循环，根据倒计时进度计算当前帧
- **大小**: `scale = (cs * 0.95) / maxDim`（占格子95%，额外 ×1.1 放大）

### 2.2 墙壁精灵图动画
- **普通鼠**: 循环播放 idle 动画
- **精英鼠**: 
  - 满血: 循环 idle
  - 受伤: 播放一次 `enemy_elite_break` 过渡动画（非循环）
  - 破损后: 循环 `enemy_elite_break_idle`
  - 死亡: 播放一次 `enemy_elite_death`

### 2.3 静态炸弹动画
- **Sleep 状态**: 静态图片，无动画
- **激活后**: 使用对应等级的动态炸弹精灵图，循环播放
- **大小参数演变**:
  - v0.7.4: 0.8（占格子80%）
  - v0.7.5: 0.95（占格子95%）
  - v0.7.6: 2.0（激活后放大）
  - v0.7.7: 1.8 → **1.5（最终）**

### 2.4 死亡动画
- **触发**: 墙壁 HP ≤ 0 时
- **类型**: 非循环播放一次
- **帧数**: 普通鼠 12 帧，精英鼠 10 帧
- **时长**: 约 0.4-0.5 秒

## 3. 特效系统

### 3.1 爆炸特效
- **类型**: 纯 Canvas 绘制，无外部资源
- **层次**:
  1. 核心闪光（白色/黄色）
  2. 冲击波（橙色扩散）
  3. 光晕（红色渐变）
- **技术**: `globalCompositeOperation = 'lighter'` 实现发光效果
- **问题**: 光晕溢出网格边界，视觉上不美观（待优化）

### 3.2 十字格蔓延爆炸
- **中心格**: 脉动效果，红→橙渐变
- **中段格**: 沿臂方向亮条
- **末端格**: 10Hz 闪烁，白色内芯

### 3.3 碎片物理
- **数量**: 每格 8-12 个碎片
- **运动**: 重力抛物线
- **生命周期**: 0.5-1 秒淡出

### 3.4 升级特效
- **触发**: 炸弹进化时
- **效果**: 双环扩散 + 旋转星光
- **颜色**: 根据进化等级变化

### 3.5 浮动文字
- **类型**: 得分提示、连击提示
- **动画**: 缩放弹出 + 向上浮动 + 2秒淡出
- **状态**: 基础版已实现，飘字/艺术数字待优化

## 5. 关卡系统

### 5.1 关卡配置
- **总数**: 18 关（完整配置）
- **格式**: JSON 文件，每关独立配置
- **验证**: `test-levels.js` 自动化检查可解性

### 5.2 关卡元素
```javascript
{
  gridSize: 5,           // 网格大小
  bombCount: 3,          // 可用炸弹数
  walls: [...],           // 墙壁配置
  staticBombs: [...],    // 静态炸弹配置
  targetScore: 100       // 目标分数
}
```

### 5.3 静态炸弹机制
- **初始状态**: Sleep（未激活）
- **激活条件**: 被爆炸范围覆盖
- **激活后**: 
  - 保持原等级（不升级）
  - 启动 3 秒倒计时
  - 大小: 占格子 1.5 倍
- **再次爆炸**: 升级 + 重置倒计时
- **倒计时结束**: 自动爆炸

### 5.4 计分系统
- **基础分**: 1级 5 分，2级 10 分
- **连击**: ×2, ×4, ×8
- **静态炸弹激活**: 5 分
- **显示**: 2 秒淡出提示

## 6. 技术架构

### 6.1 分层结构
```
src/
├── core/           # 游戏逻辑层
│   ├── GameLogic.js    # 主逻辑
│   ├── Grid.js         # 网格系统
│   └── LevelData.js    # 关卡数据
├── view/           # Canvas 渲染层
│   └── Renderer.js     # 渲染器
├── data/           # 数据存档
│   └── Storage.js      # 微信存储
└── system/         # 系统层
    ├── Audio.js        # 音效
    └── Ad.js           # 广告（预留）
```

### 6.2 事件系统
```javascript
// 回调模式（非数组收集）
constructor() { this.onEvent = null; }
emitEvent(type, data) {
  if (this.onEvent) this.onEvent({ type, ...data });
}
```

### 6.3 微信 API
- **Canvas**: `wx.createCanvas()` 获取主画布
- **存储**: `wx.getStorageSync` / `wx.setStorageSync`
- **音效**: `wx.createInnerAudioContext`
- **Polyfill**: `Object.getPrototypeOf(ctx).roundRect` 注入

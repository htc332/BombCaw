**版本**: v1.0  
**日期**: 2026-07-25  
**状态**: 设计阶段，待确认  
**目标**: 建立完整的1000关关卡生成规则体系

## 一、核心设计哲学

### 1.1 玩家体验目标
- **前50关**: 轻松上手，建立信心，积分持续增长
- **50-500关**: 波动上升，累积与消耗交替，保持心流
- **500关后**: 极限挑战，以消耗为主，考验长期策略

### 1.2 随机性设计
- **除第1关外**，每次从5关中随机选择1关
- **保底机制**: 连续3关难度关后，第4关必为奖励关
- **标签不变**: 关卡显示标签固定，内部随机池动态调整

|---------|---------|---------|---------|---------|

| 501-1000 | 10×10 | 100 | 极限挑战 | 终止 |

### 2.2 空间分配规则

**核心原则**: 元素占据空间逐步增大，预留玩家空间递减

| 棋盘尺寸 | 初始预留空间 | 最终预留空间 | 空间增长曲线 |
|---------|------------|------------|------------|
| 5×5 | 10格 | 5格 | 线性递减 |
| 6×6 | 14格 | 5格 | 线性递减 |
| 7×7 | 18格 | 5格 | 线性递减 |
| 8×8 | 22格 | 5格 | 线性递减 |
| 9×9 | 26格 | 5格 | 线性递减 |
| 10×10 | 30格 | 5格 | 线性递减 |

**计算公式**:
```
预留空间 = max(5, 初始预留 - (当前关卡-关卡起始) * 递减率)
递减率 = (初始预留 - 5) / 该阶段关卡数
```

**示例（5×5阶段）**:
- 第1关: 25 - 10 = 15格可放置元素
- 第25关: 25 - 7 = 18格可放置元素
- 第50关: 25 - 5 = 20格可放置元素（达到最大密度）

## 三、积分系统设计

### 3.1 积分公式

```
预期收益积分 = 预期可获得积分 - 预期需投入积分
```

### 3.2 关卡类型定义

| 类型 | 预期收益 | 设计目标 | 出现规律 |
|-----|---------|---------|---------|
| **累积关** | > 0 | 玩家策略正确可盈利 | 主要类型 |
| **消耗关** | = 0 | 最理想情况也仅保本 | 每50关后出现5关 |
| **奖励关** | >> 0 | 大量静态炸弹，轻松盈利 | 保底触发或随机出现 |

### 3.3 阶段积分策略

#### 阶段1: 1-50关（新手期）
- **所有关卡**均为累积关
- 预期收益: +2 ~ +5分/关
- 目标: 让玩家积分从10增长到100+

#### 阶段2: 51-500关（成长期）
- **50关累积** + **5关消耗**循环
- 累积关预期收益: +1 ~ +3分/关
- 消耗关预期收益: 0分/关（最理想情况）
- 目标: 积分波动上升，建立紧张感

#### 阶段3: 501-1000关（极限期）
- **以消耗关为主**（80%）
- 累积关预期收益: +1分/关（极少）
- 消耗关预期收益: 0或-1分/关
- 目标: 考验玩家长期积累的策略和资源管理

### 3.4 积分计算示例

**累积关示例**:
```
关卡配置:
- 10只普通鼠（+10分）
- 2个静态炸弹（节省4分放置成本）
- 玩家需放置3颗炸弹（-6分）

预期可获得: 10分（老鼠）
预期需投入: 6分（炸弹）- 4分（静态炸弹节省）= 2分
预期收益: 10 - 2 = +8分
```

**消耗关示例**:
```
关卡配置:
- 8只普通鼠（+8分）
- 0个静态炸弹
- 玩家需放置4颗炸弹（-8分）

预期可获得: 8分
预期需投入: 8分
预期收益: 0分（最理想情况）
```

## 四、老鼠投放规则

### 4.1 老鼠类型解锁表

| 关卡范围 | 普通鼠 | 加固鼠 | 幽灵鼠 | 墙壁鼠(Wall) |
|---------|-------|-------|-------|------------|
| 0-25 | ✅ | ❌ | ❌ | ❌ |
| 25-50 | ✅ | ✅ | ❌ | ❌ |
| 50-150 | ✅ | ❌ | ✅ | ❌ |
| 150-200 | ✅ | ❌ | ✅ | ❌ |
| 200-500 | ✅ | ✅ | ✅ | ✅ (≤30%) |
| 500-1000 | ✅ | ✅ | ✅ | ✅ (逐步增加) |

### 4.2 老鼠类型属性

| 类型 | 血量 | 得分 | 特殊机制 |
|-----|-----|-----|---------|
| 普通鼠(normal) | 1 | +1 | 无 |
| 加固鼠(strong) | 2 | +1 | 需2次爆炸 |
| 幽灵鼠(ghost) | 1 | +1 | 周期性显隐 |
| 墙壁鼠(wall) | 3 | +1 | 阻挡爆炸，不可通行 |

### 4.3 投放密度规则

```
老鼠总数 = 总格子数 - 预留空间 - 静态炸弹数

类型分配算法:
1. 根据关卡范围确定可用类型
2. 普通鼠作为基础填充（至少50%）
3. 特殊鼠按权重随机分配
4. 墙壁鼠在200-500关不超过30%
```

## 五、静态炸弹牛投放规则

### 5.1 投放策略

**核心原则**: 先多后少，奖励关才有

| 关卡范围 | 投放策略 | 出现频率 |
|---------|---------|---------|
| 1-100 | 每关都有 | 100% |
| 101-500 | 每5关1关 | 20% |
| 501-1000 | 每10关1关 | 10% |

### 5.2 静态炸弹类型分布

| 类型 | 爆炸范围 | 投放关卡 |
|-----|---------|---------|
| LV1 (evo=0) | 十字1格 | 1-50关 |
| LV2 (evo=2) | 竖直2格 | 25-100关 |
| LV3 (evo=3) | 横向2格 | 50-200关 |
| LV4 (evo=5) | 十字+对角 | 100关后 |

### 5.3 布局约束

**必须满足**: 静态炸弹附近有可被炸到的老鼠

```
验证算法:
对于每个静态炸弹:
  计算其爆炸范围
  检查范围内至少有一只老鼠
  如果不满足，重新生成位置
```

### 8.2 关卡生成算法

```javascript
function generateLevel(levelNumber, playerScore) {
  // 1. 确定棋盘尺寸
  const gridSize = getGridSize(levelNumber);
  
  // 2. 确定预留空间
  const reserved = calculateReservedSpace(levelNumber, gridSize);
  
  // 3. 确定关卡类型（累积/消耗/奖励）
  const levelType = determineLevelType(levelNumber, playerScore);
  
  // 4. 确定是否投放静态炸弹
  const hasStaticBombs = shouldHaveStaticBombs(levelNumber, levelType);
  
  // 5. 生成老鼠布局
  const enemies = generateEnemies(levelNumber, gridSize, reserved, hasStaticBombs);
  
  // 6. 生成静态炸弹（如果有）
  const staticBombs = hasStaticBombs 
    ? generateStaticBombs(levelNumber, gridSize, enemies) 
    : [];
  
  // 7. 验证可解性
  if (!validateSolvability(enemies, staticBombs, gridSize)) {
    return generateLevel(levelNumber, playerScore); // 重新生成
  }
  
  return {
    gridSize,
    hint: generateHint(levelType),
    walls: enemies,
    staticBombs,
    expectedProfit: calculateExpectedProfit(enemies, staticBombs)
  };
}
```

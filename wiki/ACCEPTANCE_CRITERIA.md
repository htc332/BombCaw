## 三、详细验收标准

### 3.1 功能验收标准

#### 核心玩法
| 功能 | 验收标准 | 测试方法 |
|------|----------|----------|
| 放置炸弹 | 点击空白格，炸弹正确放置，倒计时开始 | 手动测试3次 |
| 炸弹爆炸 | 3秒后爆炸，十字+对角范围正确 | 观察爆炸范围 |
| 墙壁摧毁 | 爆炸范围内的墙壁被摧毁 | 检查墙壁消失 |
| 精英鼠HP | 精英鼠需2次爆炸才死亡 | 放置炸弹观察 |
| 静态炸弹激活 | 爆炸范围内的静态炸弹被激活 | 观察连锁反应 |
| 炸弹升级 | 相邻炸弹升级，范围扩大 | 观察升级特效 |
| 胜负判定 | 墙全清=胜利，炸弹用完=失败 | 通关/失败测试 |
| 延迟结算 | 等动画播完才进入结算 | 观察结算时机 |

#### 关卡系统
| 功能 | 验收标准 | 测试方法 |
|------|----------|----------|
| 关卡加载 | JSON配置正确加载，网格生成正确 | 逐关测试 |
| 星级评定 | 根据炸弹使用数评定1-3星 | 通关后检查 |
| 连击计分 | 连续爆炸有连击加分 | 观察分数变化 |
| 关卡解锁 | 通关后解锁下一关 | 检查解锁状态 |

#### UI系统
| 功能 | 验收标准 | 测试方法 |
|------|----------|----------|
| 主菜单 | 开始游戏、关卡选择、设置按钮可用 | 点击测试 |
| 关卡选择 | 显示18关，已解锁/未解锁状态正确 | 视觉检查 |
| 游戏HUD | 显示当前炸弹数、得分、关卡 | 游戏中观察 |
| 结算界面 | 显示星级、得分、下一关/重试按钮 | 通关后检查 |
| 暂停菜单 | 暂停/继续/重试/返回主菜单 | 游戏中测试 |

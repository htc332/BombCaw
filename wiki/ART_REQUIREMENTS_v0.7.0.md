## 二、新增美术需求

### 2.1 购买栏 UI（底部新增）

**位置**: 屏幕底部，信息区下方，高度约 **100px**  
**背景**: 与现有底部信息区一致，`rgba(22,33,62,0.6)` 半透明深色

#### 需求1: 购买栏背景条
- **尺寸**: 宽度=屏幕宽，高度=100px
- **样式**: 圆角矩形，半透明深色背景
- **颜色**: `#16213E` 80%透明度
- **边框**: 顶部1px细线，`rgba(255,255,255,0.15)`
- **格式**: PNG，9-patch或纯色可平铺

#### 需求2: 4个炸弹牛图标（购买栏用）
- **尺寸**: 60×60px（每个图标）
- **样式**: 圆形或圆角方形按钮
- **状态**: 需要3种状态
  1. **未选中**: 正常颜色，无发光
  2. **选中**: 高亮边框，金色发光效果
  3. **不可选**: 灰色半透明，禁用状态

| 等级 | 基础颜色 | 选中效果 | 不可选效果 |
|------|----------|----------|------------|
| Lv1 | `#E5C84B` 金色 | 金色边框+内发光 | 灰色 `#666666` |
| Lv2 | `#5BA3F5` 蓝色 | 蓝色边框+内发光 | 灰色 `#666666` |
| Lv3 | `#C084FC` 紫色 | 紫色边框+内发光 | 灰色 `#666666` |
| Lv4 | `#FF4444` 红色 | 红色边框+内发光 | 灰色 `#666666` |

- **图标内容**: 简化的炸弹牛头像（正面或45度角），突出牛角和炸弹特征
- **格式**: PNG，透明背景，每种等级3张状态图

#### 需求3: 消耗得分标签
- **尺寸**: 适配图标下方，约40×20px
- **样式**: 小标签，圆角矩形
- **颜色**: 背景 `#1A1A2E` 半透明，文字 `#FFFFFF`
- **内容**: 显示数字（如"0"、"20"、"50"、"100"）
- **格式**: 不需要单独图，程序用文字绘制，但需要标签背景样式参考

#### 需求4: 选中指示器
- **尺寸**: 适配图标上方，约20×10px
- **样式**: 小三角形或下箭头，指向选中的图标
- **颜色**: `#E5C84B` 金色
- **动画**: 选中时上下浮动
- **格式**: PNG，透明背景

### 2.2 得分显示增强

#### 需求5: 得分数字背景
- **尺寸**: 约120×40px
- **样式**: 圆角矩形标签，带轻微内阴影
- **颜色**: 背景 `rgba(20,30,50,0.7)`，边框 `rgba(255,255,255,0.2)`
- **位置**: 顶部得分区居中
- **格式**: 9-patch PNG 或纯色可平铺

#### 需求6: 得分增加飘字效果（可选）
- **尺寸**: 约80×30px
- **样式**: 金色文字"+10"、"+20"等，带向上飘动轨迹
- **颜色**: `#FFD700` 金色，带轻微发光
- **动画**: 从得分位置向上飘出，2秒内淡出
- **格式**: 不需要单独图，程序用动态文字实现，但需颜色参考

---

### 2.3 提示弹窗

#### 需求7: 提示气泡框
- **尺寸**: 约200×60px（可缩放）
- **样式**: 圆角矩形对话框，带下箭头指向触发位置
- **颜色**: 背景 `rgba(30,42,74,0.9)`，边框 `#E5C84B` 金色1px
- **文字区域**: 居中，支持2行文字
- **格式**: 9-patch PNG，支持拉伸

#### 需求8: 提示图标（可选）
- **尺寸**: 24×24px
- **样式**: 感叹号或信息图标
- **颜色**: `#E5C84B` 金色
- **用途**: 提示框左侧小图标
- **格式**: PNG，透明背景

---

### 2.4 购买栏与现有界面的衔接

#### 需求9: 底部过渡条
- **尺寸**: 宽度=屏幕宽，高度=20px
- **样式**: 渐变过渡，从棋盘底部到购买栏顶部
- **颜色**: 从透明到 `#16213E` 的渐变
- **用途**: 柔化棋盘与购买栏的边界
- **格式**: PNG，可平铺或渐变图

## 五、参考与约束

### 5.1 必须遵循的现有规范
1. **颜色**: 使用文档中定义的色值，保持视觉一致性
2. **圆角**: 所有矩形UI元素使用 8px 圆角（与现有按钮一致）
3. **描边**: 选中状态使用 2px 描边，颜色与元素同色
4. **阴影**: 不使用硬阴影，使用内发光或外发光表现层次

### 5.2 技术约束
1. **文件大小**: 每个PNG不超过 50KB，总计不超过 500KB
2. **尺寸**: 以 iPhone 6/7/8（375×667逻辑像素）为基准设计
3. **高清**: 提供 @2x 版本（750×1334）
4. **透明**: 所有图标必须有透明背景

### 5.3 现有代码中的绘制逻辑（供参考）

```javascript
// 购买栏绘制区域（程序已实现）
const barHeight = 100; // 购买栏高度
const itemWidth = screenWidth / 4; // 4个图标等分

// 背景绘制
ctx.fillStyle = 'rgba(22,33,62,0.6)'; // 半透明深色
ctx.fillRect(0, screenHeight - barHeight, screenWidth, barHeight);

// 图标绘制位置（中心点）
const iconX = index * itemWidth + itemWidth / 2;
const iconY = screenHeight - barHeight + 50; // 垂直居中

// 选中状态
ctx.strokeStyle = '#E5C84B'; // 金色边框
ctx.lineWidth = 3;
ctx.strokeRect(iconX - 32, iconY - 32, 64, 64);
```

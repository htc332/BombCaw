# 提交信息规范

## 前缀格式
```
[类型] 简要描述

详细说明（可选）
```

## 类型说明
- **[自动]** - 自动备份/定时生成
- **[修复]** - Bug 修复
- **[功能]** - 新功能开发
- **[优化]** - 性能/代码优化
- **[文档]** - 文档更新
- **[重构]** - 代码重构
- **[测试]** - 测试相关

## 示例
```
[修复] 清除TypeScript编译缓存，修复Missing class导致的黑屏

问题：Cocos Creator 3.8.8 构建时所有自定义脚本类缺失
原因：TypeScript编译缓存损坏
解决：删除temp/和library/目录，重启编辑器重新编译
```

## Git Hooks 配置
项目已配置 `.git-hooks/pre-commit`：
- 阻止提交 `temp/` 和 `library/` 目录
- 警告 `.log` 文件提交
- 提醒提交信息添加规范前缀

## 自动提交提醒
建议设置定时任务（cron）进行自动备份：
```bash
# 每天自动提交（示例）
0 2 * * * cd ~/Desktop/bomb-wall && git add -A && git commit -m "[自动] 每日备份 $(date +%Y-%m-%d)"
```

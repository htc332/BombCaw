# UI布局重构方案 v5

## 修改日期
2026-06-17

## 修改背景
将已有积分和购买栏放在一起，优化信息层级，提升界面清晰度。

## 最终布局结构（从上到下）

```
┌─────────────────────────┐
│         关卡: 1          │  ← 独立一行，14px，居中，纯文字
├─────────────────────────┤
│   消灭:5只  剩余:3只    │  ← 统计信息，14px，一行，纯文字
├─────────────────────────┤
│                         │
│      游戏棋盘 (5x5)      │  ← 大小位置完全不变
│                         │
├─────────────────────────┤
│  点击上方格子盘放置牛牛   │  ← 12px，动态提示（棋盘下方）
├─────────────────────────┤
│    [牛奶图片] 15        │  ← 14px，居中，用游戏内牛奶图片
├─────────────────────────┤
│ [白] [蓝] [紫] [红]      │  ← 购买栏（原有逻辑不变）
│ -2   -3   -4   -5
└─────────────────────────┘
```

## 修改文件清单

### 1. Renderer.js

#### calcLayout 调整
- `funcBtnH = 0`（移除顶部功能按钮区）
- `scoreH = 0`（移除顶部得分区）
- 新增 `levelH = 30 * s * pr`（关卡编号高度）
- 新增 `statsH = 25 * s * pr`（统计信息高度）
- 棋盘 `offsetY = levelH + statsH`（棋盘下移，给上方信息留空间）

#### render 方法调整
- 移除 `drawFuncButtons()` 调用
- 移除 `drawScorePanel()` 调用
- 新增 `drawLevel(state, w, levelH)` 调用
- 新增 `drawStats(state, w, levelH, statsH)` 调用

#### 新增 drawLevel 方法
- 内容：`关卡: X`
- 字体：14px
- 对齐：居中
- 颜色：`#FFD700`（金色）
- 无图标

#### 新增 drawStats 方法
- 内容：`消灭:X只  剩余:Y只`
- 字体：14px
- 对齐：居中
- 颜色：`#E8D5C0`（次要文字色）
- 无图标

### 2. UIManager.js

#### renderShopBar 调整
- 提示文字位置：移回棋盘下方、购买栏上方（原位置）
- 在购买栏上方新增得分显示：`[牛奶图片] X`
- 调整 `barY` 计算：上移给得分显示留空间
- 得分显示样式：
  - 图标：使用 `this.milkIcon`（游戏内牛奶图片）
  - 字体：14px
  - 对齐：居中
  - 颜色：`#FFD700`（金色）或 `#FFF`（白色）

## 样式规范

| 元素 | 字体大小 | 颜色 | 对齐 | 图标 |
|------|---------|------|------|------|
| 关卡编号 | 14px | `#FFD700` | 居中 | 无 |
| 统计信息 | 14px | `#E8D5C0` | 居中 | 无 |
| 提示文字 | 12px | `#FFFFFF` | 居中 | 无 |
| 得分显示 | 14px | `#FFD700` | 居中 | 牛奶图片 |
| 购买栏成本 | 11px | `#FFD700`/`#FF4444` | 居中 | 牛奶图片 |

## 注意事项

1. **棋盘不变**：游戏棋盘的大小和位置保持原样，仅上方空间重新分配
2. **背景场景**：背景渲染逻辑不变，继续匹配关卡背景
3. **动态提示**：保留原有动态提示逻辑（默认提示 + 操作反馈）
4. **牛奶图标**：使用游戏内已有牛奶图片资源（`images/ui_grid.png`）
5. **无表情图标**：关卡、老鼠等均使用纯文字，不显示emoji或图标

## 冲突检查

### 与现有文档的冲突
1. **UI_DESIGN_REQUIREMENTS.md**：原设计需求中顶部有功能按钮区和得分区，本次重构移除这两个区域，将信息整合到棋盘上方
2. **SCORING_SYSTEM_V080.md**：原设计在顶部显示积分和统计，本次重构将积分下移到购买栏上方，统计上移到棋盘上方

### 与现有代码的冲突
1. **Renderer.js**：`drawFuncButtons` 和 `drawScorePanel` 方法将被移除或重构
2. **UIManager.js**：`renderShopBar` 中的提示文字位置需要调整

### 无冲突项
- 游戏核心逻辑（GameLogic.js）不受影响
- 关卡数据（LevelData.js）不受影响
- 爆炸特效和动画系统不受影响
- 音频和广告系统不受影响

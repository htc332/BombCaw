# 牛牛炸鼠 - 核心玩法设计文档

**版本**: v0.6.0  
**平台**: 微信小游戏 (Canvas 原生)  
**最后更新**: 2026-05-12

---

## 一、核心概念

### 1.1 游戏定位
- **类型**: 纯单机益智解谜游戏
- **核心体验**: 策略规划 + 连锁反应的爽快感
- **目标玩家**: 休闲玩家，喜欢动脑但不追求操作
- **单局时长**: 30秒 ~ 2分钟

### 1.2 一句话描述
> 放置炸弹牛，利用连锁爆炸摧毁所有墙壁。相邻炸弹会进化升级，爆炸范围更大！

---

## 二、核心机制

### 2.1 基础操作
| 操作 | 规则 | 限制 |
|------|------|------|
| 放置炸弹 | 点击空白格子 | 不能放在墙壁/已有炸弹上 |
| 炸弹倒计时 | 放置后 3 秒自动爆炸 | 不可取消 |
| 爆炸范围 | 默认十字方向 1 格 | 可进化升级 |

### 2.2 进化机制（核心创新）
```
进化等级:
Lv.0 (基础): 十字方向 1 格
Lv.1 (升级1次): 十字方向 1 格 + 对角方向 1 格 = 九格爆炸（八方向）
Lv.2 (升级2次): 十字方向 2 格
Lv.3 (升级3次): 十字方向 2 格 + 对角方向 2 格 = 十七格爆炸（八方向）
```

**爆炸范围规则:**
| 等级 | 十字方向 | 对角方向 | 总格数 | 形状 |
|------|---------|---------|--------|------|
| Lv.0 | 上下左右各1格 | 无 | 5格 | 十字 |
| Lv.1 | 上下左右各1格 | 左上/右上/左下/右下各1格 | 9格 | 3x3方块 |
| Lv.2 | 上下左右各2格 | 无 | 9格 | 大十字 |
| Lv.3 | 上下左右各2格 | 左上/右上/左下/右下各2格 | 17格 | 大八方向 |

**进化条件**: 两个炸弹（玩家放置或静态炸弹）在十字/对角相邻时，同时进化 1 级
- 相邻定义：上下左右 + 四个对角（共8方向）
- 进化是即时的，放置时立即计算
- 多个炸弹相邻时，每对相邻关系都触发进化

### 2.3 静态炸弹（关卡预设）
- **初始状态**: 灰色虚线圆形，未激活
- **激活方式**: 被任意爆炸波及后激活
- **激活后**: 显示当前等级，开始 3 秒倒计时
- **连锁**: 爆炸可激活其他静态炸弹，形成多米诺效应

### 2.4 墙壁类型
| 类型 | 外观 | HP | 特性 |
|------|------|----|------|
| 普通墙 (normal) | 砖石纹理 | 1 | 基础目标，死亡播放死亡动画 |
| 精英鼠 (strong) | 带头盔的老鼠 | 2 | 需 2 次爆炸，第一次破损头盔，第二次死亡 |
| 炸弹墙-黄 (bomb/yellow) | 黄色标记 | 1 | 爆炸后返还 1 个炸弹 |
| 炸弹墙-红 (bomb/red) | 红色标记 | 1 | 爆炸后返还 1 个炸弹并立即触发二次爆炸 |

#### 精英鼠状态机
```
[idle] --第一次爆炸--> [break_transition] --2.6秒--> [break_idle] --第二次爆炸--> [death]
```

**第一次爆炸：**
- HP 从 2 降到 1
- 播放头盔破损过渡动画（约2.6秒）
- 动画完成后切换到破损待机动画

**第二次爆炸：**
- HP 从 1 降到 0
- 播放死亡动画
- 2秒后从网格移除

## 三、胜负判定

### 3.1 胜利条件
- 所有墙壁 HP 降为 0
- **延迟结算**: 逻辑层设置 `pendingVictory = true`
- **实际结算**: 动画全部完成后（`animator.getActiveCount() === 0 && particles.getActiveCount() === 0`）
- 所有视觉反馈完整播放后再进入结算界面

### 3.2 失败条件
- 炸弹用完（`bombsLeft === 0`）
- 场上仍有墙壁 HP > 0
- 且没有已放置的未爆炸炸弹
- 且没有已激活的静态炸弹倒计时中

### 3.3 分数计算
```
基础分: 摧毁每面墙 100 分
连锁 bonus: 连续摧毁额外 +50/100/150...
剩余炸弹 bonus: 每个剩余炸弹 +200 分
星级评定: 根据分数和步数
```

## 四、资源系统

### 4.1 炸弹资源
- 每关给定固定数量（不可补充，除炸弹墙返还）
- 用完即止，必须策略规划
- **关键设计**: 资源有限 → 强迫玩家思考最优解

### 4.2 广告续命（预留）
- 失败后观看激励视频可复活
- 每次复活获得 2-3 个炸弹
- 每关最多 3 次续命

---

## 五、关卡设计哲学

### 5.1 宫本茂式教学
- **一次教一个机制**
- 让玩家自己发现乐趣，而不是文字说明
- 前 6 关为教学阶段，逐个引入核心机制

### 5.2 三阶段难度曲线
```
教学阶段 (1-6关): 逐个机制引入
应用阶段 (7-12关): 机制组合应用  
精通阶段 (13-18关): 创意挑战
```

## 六、交互设计

### 6.1 触摸反馈
- 点击格子: 轻微缩放动画 (0.95x)
- 放置炸弹: 缩放弹出 + 轻微弹跳
- 不可放置: 红色闪烁提示

### 6.2 震动反馈
```javascript
vibrateConfig: {
  enabled: true,
  light: { duration: 15 },   // 升级
  medium: { duration: 25 }, // 墙壁摧毁
  heavy: { duration: 40 }   // 爆炸
}
```
- 放置炸弹: **不震动**（避免频繁震动疲劳）
- 爆炸: heavy 震动
- 升级: light 震动

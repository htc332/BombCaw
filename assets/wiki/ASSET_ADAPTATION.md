# 炸弹推墙 · 精灵图资产适配流程

> **目标**: 建立一套标准化流程，让不同规格/大小的素材在游戏中表现统一。
>
> **核心问题**: 不同素材的"实际内容"占帧比例不同，导致游戏中视觉大小不协调
> **解决策略**: 以"最大内容边"统一，让所有素材的最大边在格子中占相同比例
> **最新状态** (2026-05-02): 牛牛炸弹已放大为主体元素，倒计时数字已移除

---

## 📋 流程概览

```
收到素材 → 分析内容边界 → 计算统一缩放 → 更新配置 → 验证效果
```

## Step 1: 收到素材后自动分析

### 工具位置
```
tools/analyze-sprites.py
```

### 使用方法
```bash
# 分析单个素材

# 例如
python3 tools/analyze-sprites.py res/images/sprite/lv1

```

### 分析指标
| 指标 | 含义 |
|------|------|
| 平均内容宽度/高度 | 实际有像素区域的平均大小 |
| 内容占帧比例 | 内容面积 / 帧面积 |
| 最大内容宽度/高度 | 所有帧中最大的内容边界（用于统一计算） |
| 垂直偏移 | 内容是否偏上或偏下，需要补偿居中 |

## Step 2: 统一缩放策略（核心）

### 核心洞察

**问题**: 不同素材的实际内容大小不同（Lv1内容只占帧49%，Lv2占81%），统一按格子缩放会导致视觉大小不协调。

**正确策略**: **以"最大内容边"统一**

```javascript
// 目标: 让所有素材的"最大内容边"在游戏中占格子相同比例
// 公式: scale = targetMaxEdge / contentMaxEdge

// targetMaxEdge = 64 * 基准scale (通常选最"标准"的素材作为基准)
// contentMaxEdge = 素材在64x64帧中的最大内容边（宽或高）
```

### 为什么不用"填充比例"统一？

之前的错误策略是让"内容面积"统一占75%，导致：
- Lv1 内容太小(31x46)，即使放大1.5倍，视觉还是不如 Lv2
- Lv3/Lv4 内容本身很大，scale<1 后反而更小
- **用户实际看到的是"最大边"决定的轮廓大小**

### 正确做法：最大边统一

以 Lv2 为基准（内容最饱满的素材）：
- Lv2: 最大内容边 = 64px, scale = 0.90
- 目标最大边 = 64 × 0.90 = 57.6px

其他素材以此为目标：
- Lv1: 最大边 = 46px, scale = 57.6/46 = **1.25**
- Lv3: 最大边 = 61px, scale = 57.6/61 = **0.94**
- Lv4: 最大边 = 62px, scale = 57.6/62 = **0.93**

## Step 3: 牛牛主体性放大（2026-05-02 最新调整）

### 用户要求
牛牛炸弹需要突出主体性，比老鼠（敌人）更大，增强视觉焦点。

### 调整原则
在最大边统一的基础上，牛牛炸弹额外放大 1.2~1.5 倍，确保游戏中炸弹是视觉中心。

### 当前配置（2026-05-02 最新）

| 素材 | 内容尺寸 | 最大边 | 基础scale | **最终scale** | 垂直偏移 | 说明 |
|------|---------|--------|----------|-------------|---------|------|
| lv1 | 32×46 | 46px | 1.25 | **1.80** | -6.5 | 内容小，大幅放大突出 |
| lv2 | 52×64 | 64px | 0.90 | **1.10** | -0.1 | 基准，保持克制 |
| lv3 | 59×61 | 61px | 0.94 | **1.50** | -1.6 | 接近基准，适度放大 |
| lv4 | 56×62 | 62px | 0.93 | **1.50** | -1.6 | 接近基准，适度放大 |
| enemy_n | 55×53 | 55px | 1.05 | **1.05** | -0.5 | 敌人保持原大小 |
| enemy_elite | 55×51 | 55px | 1.05 | **1.05** | -1.6 | 精英敌人保持原大小 |

### 关键原则

1. **牛牛炸弹 > 老鼠**: 所有炸弹 scale 都 ≥ 1.10，Lv1 达到 1.80 确保突出
2. **进化等级递进**: Lv3/Lv4 相同 scale（1.50），比 Lv2（1.10）明显更大
3. **敌人不变**: 敌人保持 1.05，不跟炸弹抢视觉焦点
4. **scale 范围控制在 1.0~1.8**: 超出范围说明素材本身需要调整
5. **垂直偏移**根据内容重心调整，让素材在格子中垂直居中

### 检查清单
1. **牛牛 vs 老鼠**: 炸弹明显比敌人更大，视觉焦点在炸弹

## 📊 常见问题诊断

### 问题1: 炸弹A看起来比炸弹B大/小
**原因**: scale 值没有按设计意图调整
**解决**: 参考上表，确保 Lv1 > Lv3/Lv4 > Lv2 的视觉层级

### 问题2: 炸弹和老鼠一样大（不够突出）
**原因**: 炸弹 scale ≤ 1.0 或敌人 scale 过高
**解决**: 炸弹 scale 应 ≥ 1.10，敌人保持 1.05

### 问题3: 素材溢出格子
**原因**: scale 值过高（>1.8）
**解决**: 降低 scale（每次减 0.05），或让美术缩小内容边界

### 问题4: 素材偏上或偏下
**原因**: 内容在帧中没有垂直居中
**解决**: 调整 yOff 值（正数=下移，负数=上移）

# 炸弹推墙 · 美术风格参考文档

## 参考目标：《天天爱消除》

**文档目的**：为炸弹推墙微信小游戏提供美术风格指导，参考天天爱消除的成熟设计体系。

---

## 一、核心设计理念

### 1.1 品牌定位
- **消除烦恼，治愈心灵** - 给玩家带来轻松愉快的体验
- **萌系治愈** - 将可爱、温暖的情感注入设计
- **无压力体验** - 休闲游戏的本质是轻量、轻松

### 1.2 设计情感关键词
| 关键词 | 解释 |
|--------|------|
| 萌系治愈 | 可爱但不幼稚，温暖但不油腻 |
| 清新明快 | 色调明亮，低饱和度，视觉清爽 |
| 轻快干练 | 简化厚重装饰，强调符号本身质感 |
| 欢乐简单 | 降低理解门槛，3秒内看懂界面 |

## 二、色彩系统

### 2.1 主色调参考
```
背景色：#0D0D15 → 建议改为更温暖的深色
主色调：#FFD700（金色）- 保持，但降低饱和度
辅助色：#FF6B6B（珊瑚红）- 活力、警示
强调色：#00D9FF（青蓝）- 科技感、清爽
```

### 2.2 天天爱消除配色特点
- **低饱和度高明度**：色彩不刺眼，长时间游戏不疲劳
- **明快清爽**：避免沉重感，整体轻盈
- **暖色为主**：营造温馨、治愈的氛围
- **清晰对比**：文字和背景有足够对比度

### 2.3 建议调整
| 当前 | 建议调整 |
|------|----------|
| #0D0D15 纯黑背景 | 改为深蓝紫渐变 #1A1A2E → #16213E |
| #FFD700 高饱和金 | 降低饱和度 #E5C100，更柔和 |
| #FF6B35 警示橙 | 改为珊瑚粉 #FF8585，更友好 |

## 三、UI 设计规范

### 3.1 设计原则（来自天天爱消除2023改版）

#### 简化厚重装饰
- ❌ 去除厚重边框、复杂装饰
- ✅ 强调图标/按钮符号本身的质感
- ✅ 为视觉减负，清爽视觉感受

#### 按钮设计
- 圆角设计，柔和友好
- 轻微投影增加层次感
- 状态变化清晰（normal/hover/pressed）

#### 面板设计
- 半透明毛玻璃效果（可选）
- 简洁的分割线代替厚重边框
- 留白充足，不拥挤

### 3.2 关卡选择界面参考

**天天爱消除设计**：
- 大地图背景，关卡分布其中
- 未解锁关卡有迷雾包裹，增加神秘感
- 关卡按钮数字清晰可见
- 当前关卡有金色边框高亮

**炸弹推墙适配**：
- 简洁的网格布局（5列）
- 圆形或圆角矩形关卡按钮
- 未解锁：灰色 + 锁图标
- 已解锁：彩色 + 数字
- 当前关卡：金色边框/发光效果
- 最佳分数：小星星标记

### 3.3 顶部栏设计

**当前问题**：纯色块，缺乏层次

**参考改进**：
- 渐变背景替代纯色
- 图标+数字组合（炸弹数、分数）
- 圆润的字体，可爱但不幼稚
- 轻微阴影增加立体感

### 3.4 底部面板设计

**参考改进**：
- 圆角大面板，而非矩形
- 渐变背景或纹理
- 提示文字居中，字体友好
- 操作按钮（如撤销、提示）用图标表示

## 四、游戏元素设计

### 4.1 炸弹牛形象
**已有资源**：Level_1~4.jpg（4个等级）

**设计要点**：
- 圆形裁剪显示（已在 Renderer.js 实现）
- 等级边框颜色区分：
  - Lv.0（基础）：金色 #FFD700
  - Lv.1（升级1次）：青色 #00D9FF  
  - Lv.2+（高级）：紫色 #FF00FF
- 发光效果增加质感
- 倒计时数字清晰可读

### 4.2 墙壁设计
**已有资源**：wall_1~3.jpg

**设计要点**：
- 普通墙：砖石纹理
- 加固墙：金属/混凝土质感，显示 HP 数字
- 炸弹墙：特殊标记（+号或炸弹图标）

### 4.3 静态炸弹（新功能）
**设计参考**：
- 未激活：灰色虚线圆形，带问号标记
- 已激活：对应等级颜色，倒计时显示
- 视觉反馈：激活时有明显的颜色变化动画

## 五、动效与反馈

### 5.1 动画原则
- **轻快**：动画时长 0.2-0.4 秒
- **弹性**：使用 ease-out 曲线，有回弹感
- **连贯**：状态切换流畅自然

### 5.2 关键动效
| 场景 | 动效建议 |
|------|----------|
| 放置炸弹 | 缩放弹出 + 轻微弹跳 |
| 炸弹爆炸 | 粒子扩散 + 屏幕震动（可选） |
| 墙壁被摧毁 | 碎裂动画 + 掉落 |
| 关卡胜利 | 星星飞入 + 分数滚动 |
| 按钮点击 | 缩放 0.95 + 颜色变暗 |

### 5.3 粒子系统
**参考天天爱消除**：
- 消除时的粒子飞散
- 连击时的特殊效果
- 胜利时的庆祝粒子

## 六、资源格式规范

### 6.1 图片格式选择
| 元素类型 | 推荐格式 | 说明 |
|----------|----------|------|
| 按钮图标 | PNG-32 | 需透明边缘，抗锯齿清晰 |
| 背景图 | JPG | 减少包体，质量 80% 即可 |
| 小动物/炸弹 | PNG | 透明背景，圆形显示 |
| 进度条 | PNG-8 | 简单色块，小体积 |

### 6.2 命名规范
```
ui_模块_功能_状态.png

示例：
ui_btn_level_normal.png      - 关卡按钮-正常
ui_btn_level_pressed.png     - 关卡按钮-按下
ui_btn_level_locked.png      - 关卡按钮-锁定
ui_panel_top.png             - 顶部面板
ui_panel_bottom.png          - 底部面板
bg_game.jpg                  - 游戏背景
bg_map.jpg                   - 关卡地图背景
icon_setting.png             - 设置图标
icon_back.png                - 返回图标
icon_bomb.png                - 炸弹图标
icon_star.png                - 星星图标
```

### 6.3 尺寸建议
| 资源类型 | 建议尺寸 | 备注 |
|----------|----------|------|
| 炸弹牛图片 | 256x256 | 圆形裁剪显示 |
| 墙壁图片 | 128x128 | 适配 70px 格子 |
| 按钮背景 | 可九宫格 | 支持拉伸 |
| 背景图 | 750x1334 | 2x 分辨率 |
| 图标 | 64x64 | 高清显示 |

## 八、开发注意事项

### 8.1 性能优化
- 背景图使用 JPG，减少包体积
- 小图标合并为图集（如使用）
- 图片尺寸保持 2 的幂次方（如 256x256）

### 8.2 微信小游戏限制
- 总包大小限制（4MB 主包）
- 图片预加载策略
- 异步加载避免卡顿

### 8.3 适配考虑
- 多分辨率适配（iPhone/Android 各种屏幕）
- 安全区域处理（刘海屏、圆角屏）

# 2026-05-31 教训记录

## Git 规范教训
- **问题**：修改 bomb-wall 项目时没有按规范进行 git 备份
- **后果**：代码修改后无法回滚，出现问题难以恢复
- **正确做法**：
  1. 每次修改前创建分支或确保在干净状态
  2. 修改后及时提交 commit
  3. 重要节点打 tag
  4. 重大修改前先备份

## Cocos Creator 资源数据库
- **问题**：删除了 library/ 目录导致 Cocos 资源索引丢失
- **后果**：所有脚本类无法被识别，构建失败，运行黑屏
- **正确做法**：
  1. 不要手动删除 library/ 目录
  2. 如果必须清理，要通过 Cocos 编辑器重新导入
  3. 缓存问题优先用编辑器解决，不是命令行

## 优先级错误
- **问题**：把构建问题放在运行时黑屏之前解决
- **后果**：没有抓住核心问题（运行时无法运行）
- **正确做法**：优先解决运行时问题，构建是后续步骤
